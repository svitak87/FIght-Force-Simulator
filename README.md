# ⚔️ Fight Force Simulator

Juego de combate por turnos desarrollado con **JavaScript**, creado como ejercicio práctico para trabajar conceptos fundamentales de programación.

## 🎮 Características

El jugador puede:

* ⚔️ Atacar al enemigo.
* ❤️ Recuperar su vida.
* 🏃 Huir del combate.
* 🧪 Usar una poción mágica con resultados aleatorios.
* 🎲 Tomar decisiones que afectan el resultado de la pelea.

## 🧠 Conceptos practicados

* `while`
* `switch`
* `if / else`
* Variables y operadores
* `prompt()` y `alert()`
* Control de estados mediante variables
* Lógica de juego y condiciones

## 🚀 Ejecución

Abrir el archivo JavaScript/HTML en un navegador y comenzar la pelea.

**Objetivo:** derrotar al enemigo antes de que la vida del jugador llegue a `0`.
